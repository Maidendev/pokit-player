# FFmpeg Binaries

This directory holds platform-specific FFmpeg binaries for production builds.

**On Replit**: FFmpeg is provided by the Nix environment (`replit.nix`) — no binaries needed here.

**For production builds**, download and place the following:

| File | Platform | Size |
|------|----------|------|
| `ffmpeg-darwin` | macOS Intel (x64) | ~76 MB |
| `ffmpeg-darwin-arm64` | macOS Apple Silicon | ~44 MB |
| `ffmpeg.exe` | Windows x64 | ~79 MB |

See `REPLIT_SETUP.md` for download instructions.
